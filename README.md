# Jingbo Wang's homepage

The homepage is [`index.html`](index.html), served directly from the site root. The old [`design-preview.html`](design-preview.html) URL forwards to it. The interactive robot playground is [`robot-reference.html`](robot-reference.html); see [`ROBOT_REFERENCE.md`](ROBOT_REFERENCE.md) for its modules and model sources.

Serve the repository root with a local HTTP server to preview the site. The older Jekyll content in `_pages/` and `_publications/` is retained as source material while the new homepage is being finalized.

The Chiikawa model is by [the_FA](https://sketchfab.com/the_FA), sourced from [Sketchfab](https://sketchfab.com/3d-models/chiikawa-e0ededadc41149dbbc80774d021a50e7) under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Its glTF vertex data were repacked for web delivery without changing the mesh shape or texture. The homepage composition and selected visual styles were adapted from [oplisty/oplisty.github.io](https://github.com/oplisty/oplisty.github.io). Robot model sources are documented in [`ROBOT_REFERENCE.md`](ROBOT_REFERENCE.md); vendored JavaScript licenses remain alongside their files.
